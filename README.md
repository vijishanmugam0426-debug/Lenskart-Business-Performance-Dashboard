#  Lenskart Business Performance Dashboard

##  Project Overview
This project is an interactive Excel dashboard created to analyze business performance data for Lenskart.

The dashboard provides insights into:
- Total Sales
- Total Orders
- Product Performance
- Customer Age Group Analysis
- Gender-wise Sales
- Monthly Sales Trends
- State-wise Sales Distribution

---

##  Tools & Skills Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Treemap Chart
- Map Chart
- Data Visualization

---

✅ Interactive Dashboard

## KPIs Included
- Total Sales
- Total Orders
- Total Quantity
- Average Sales per Order
- Last Updated Date
